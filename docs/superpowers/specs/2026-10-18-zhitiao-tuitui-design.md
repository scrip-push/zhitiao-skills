# 纸条推推技能设计

用户已确认：创建公开仓库 `scrip-push/zhitiao-skills`，首个技能放在 `skills/zhitiao-tuitui`，配合已发布的纸条 CLI 使用。

## 方案

采用 SKILL.md 加 CLI 参数参考和 Codex UI 元数据。仓库根 README 负责安装及调用示例；技能指令负责需求转查询、授权处理、分页范围、结果整理与事实边界。纯 Markdown 方案直接调用 CLI，不增加 API 客户端、后台服务或环境变量。相比再包一层脚本，可避免重复实现现有认证与重试；相比把说明放入 CLI 仓库，可独立分发技能。

## 范围

包 `@hrbully/zt-cli@0.1.0`，Node.js 24+；招聘公告、本人面经、本人投递的列表与详情。按需查询；授权有效时直接复用，未登录时交给用户在官网授权。返回事实与建议分开，保留真实来源、权限边界、实时分页和部分结果说明。

## 验收

技能格式校验通过；所有示例参数与已发布 CLI 帮助一致；用实际已授权 CLI 完成发现、列表和详情查询，并检查错误退出码。公开 main 包含完整技能及安装文档，不提交个人业务数据或凭证。
